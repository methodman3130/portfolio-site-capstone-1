# Vitruvius John D. Barayuga — Portfolio

A responsive personal portfolio built with semantic HTML, Bootstrap 5, custom CSS, and basic JavaScript.

## Features

- Responsive single-page layout
- Light and dark themes with saved preference
- Accessible navigation and reduced-motion support
- Scroll reveal and active navigation effects
- Professional biography, roles, focus areas, and work directions
- GitHub profile integration

## Local preview

Open `index.html` in a browser, or run a simple static server from this directory.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the default branch and the `/ (root)` folder, then save.

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
